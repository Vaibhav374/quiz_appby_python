# 🧠 Online Quiz Platform (Python)

A Python-based command-line quiz application designed for educational or entertainment purposes. It allows users to take customizable quizzes, track their scores, and get feedback—all in an interactive and user-friendly interface.

---

## ✅ Features

- 🎯 **Customizable Questions** – Easy to add or modify questions.
- 📝 **Multiple-Choice Format** – Clear and structured quiz interface.
- 📊 **Scoring System** – Tracks and displays scores upon completion.
- 🔁 **Replay Option** – Users can retake quizzes for practice or fun.
- 🎓 **Educational Utility** – Great for learning and assessment.

---

## 🧰 Technologies Used

- **Python 3.x**
- No external libraries required (uses built-in features like `input()` and control flow)
